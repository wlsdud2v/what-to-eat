# 오늘 뭐 먹지? 🍚

현재 위치의 **날씨·계절·지역 특산**과 **점심/저녁**을 반영해 메뉴를 추천하고, 그 메뉴를 파는 **주변 식당을 카카오맵과 목록**으로 보여주는 웹 앱입니다.
지도·식당 검색·위치 검색·주소 변환은 모두 **카카오맵 JavaScript SDK**를 쓰고, 카카오 키가 없거나 SDK 를 못 불러오면 OpenStreetMap(Leaflet·Overpass)으로 자동 대체됩니다.

## 카카오 키 설정

1. [Kakao Developers](https://developers.kakao.com) → 내 애플리케이션 → 앱 만들기
2. **앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인** 에 등록: `http://localhost:8000`, `https://wlsdud2v.github.io`
   - 경로(`/what-to-eat/`)·끝 슬래시 없이 **출처만** 적습니다. 등록 안 된 도메인이면 카카오가 SDK 요청을 401(domain mismatched)로 거부해 OSM 지도로 대체됩니다.
   - ⚠️ **제품 링크 관리 → 웹 도메인** 은 카카오톡 공유 링크용이라 여기에 넣으면 지도가 동작하지 않습니다.
3. **제품 설정 → 카카오맵** 사용 설정 ON
4. 같은 **JavaScript 키**를 `config.js` 의 `window.KAKAO_JS_KEY` 에 붙여넣기 (REST API 키 아님)

JavaScript 키는 등록한 도메인에서만 동작하므로 정적 호스팅에 그대로 올려도 됩니다.
키가 비어 있거나 SDK 로드가 실패하면 콘솔에 경고를 남기고 지도는 Leaflet + OSM 타일(필요할 때만 불러옴), 식당은 Overpass(OSM)로 대체합니다.

## 실행

위치 권한(Geolocation)은 `https` 또는 `localhost` 에서만 동작하므로 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
cd what-to-eat
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

배포는 GitHub Pages·Netlify 등 정적 호스팅에 폴더째 올리면 됩니다.

## 화면 구성

디자인은 **B안 「식욕 자극」**입니다. 노을 하늘 아래 나무 식탁에 오늘의 한 그릇이 놓이고, 아래쪽은 짙은 갈색 카드(`#2B1F18`)에 주황 강조색(`--accent: #FF9F43`) 하나로 통일합니다. 화면은 늘 어두운 톤이라 `color-scheme: dark` 입니다.

1. **히어로** — 화면 전체에 오늘 날씨의 하늘(맑음·구름 조금·흐림·안개·비·뇌우·눈·무더위·한파 × 낮/해 질 녘/밤)이 깔리고, 아래에 노을 언덕과 나무 식탁, 그 위에 추천 1위 메뉴가 담긴 그릇이 놓입니다.
   - 위: 동네 이름, 날씨 알약(`맑음 10° · 체감 9° · 가을`), 📍 근처 식당 메뉴만 · 👶 아이와 함께 · 💗 내 메뉴 관리 · 설정 버튼.
   - 가운데: `쌀쌀한 토요일 저녁, 오늘은` + 아주 큰 메뉴 이름 + 한 줄 설명 + 대표 근거 배지(`🌧️ 날씨 추천` 등)·`근처 N곳`·분류 칩 + 근거 2줄.
   - 그릇: 뜨거운 메뉴(`temp: hot`)는 김 나는 국그릇, 차가운 메뉴는 얼음 띄운 그릇, 나머지는 접시. 국물 색은 이름·설명으로 빨강(얼큰)·갈색(된장·국밥)·맑음·크림 중에 고릅니다(`app.js` 의 `dishOf()`).
   - 아래 버튼: ♡ 좋아하는 메뉴, 🚫 추천에서 빼기(알림의 `되돌리기` 로 취소), **주변 식당 보기**, 다시 추천.
   - 저녁 16시 이후 낮이고 맑은 계열이면 해 질 녘 노을 하늘(`Sky.set({ dusk: true })`)을 씁니다.
   - 넓은 화면(900px 이상)에서는 글은 왼쪽, 그릇은 오른쪽에 놓입니다.
2. **이런 메뉴도** — 나머지 추천 5개를 작은 그릇 그림으로 보여주고 아래에 추천 점수 곡선을 그립니다. 누르면 그 메뉴가 히어로로 올라가고, `추천 근거 보기` 로 6개 메뉴의 근거를 펼쳐 볼 수 있습니다. 좋아하는 메뉴는 분홍 테두리와 ♥ 로, 히어로에서는 `💗 내 최애` 로 강조됩니다.
3. **지금 갈 수 있는 곳** — 반경을 걸어서 걸리는 시간(약 67m/분)으로 바꿔 `걸어서 15분 안에 칼국수 한 그릇 · 14곳` 처럼 보여줍니다. 누르면 주변 식당으로 내려갑니다.
4. **주변 식당** — 지도와 번호 목록(메뉴 일치는 주황 번호). 카카오맵·네이버지도 링크.
5. **집에서 만들어 먹기** — 레시피 검색. 아래 「레시피 검색」 참고.
6. **검색 · 추천 설정** — 위치 검색, 끼니, 날씨 직접 선택, 반경, 음식 종류 제외, 📍 근처 식당 메뉴만 스위치(히어로 📍 버튼과 같은 설정, `what-to-eat:near-only:v1`, 켜면 히어로에 `📍 근처 식당 메뉴` 칩), 👶 아이와 함께 스위치(히어로 버튼과 같은 설정, `what-to-eat:kid-only:v1`), 🥗 가벼운 식사 스위치(`what-to-eat:light-only:v1`, 켜면 히어로에 `🥗 가볍게` 칩), 🍶 반주·안주 스위치(`what-to-eat:drink-only:v1`, 켜면 히어로에 `🍶 반주·안주` 칩), 추천 제외 메뉴 관리 링크. 위치를 바꾸면 맨 위로 돌아가 새 추천을 보여줍니다.
7. **아래 내비** — 내 메뉴 관리, 추천 6개 점(눌러서 바로 고르기), 위치 검색.

**내 메뉴 관리 페이지** (`favorites.html`, 상단 `💗`·`🚫` 버튼) — 탭 세 개로 좋아하는 메뉴·직접 추가 메뉴·추천 제외 메뉴를 관리합니다. `favorites.html#custom` 은 직접 추가 탭, `#excluded` 는 추천 제외 탭을 먼저 엽니다.

- **💗 좋아하는 메뉴** — 메뉴 이름으로 추가(646종 + 직접 추가 메뉴 자동완성), 삭제, 🚫 로 추천 제외 탭으로 옮기기. 목록에 없는 이름은 `직접 추가` 줄로 바로 추가하면 비슷한 메뉴 정보로 직접 추가 메뉴가 함께 만들어집니다.
- **✏️ 직접 추가** — 목록에 없는 메뉴를 만들어 **추천에도 나오게** 합니다. 이름을 넣으면 이름이 가장 비슷한 기존 메뉴(`닭칼국수` → `칼국수`)의 분류·온도·끼니·계절·날씨·특징(아이 OK·가벼운 식사·반주)을 미리 채우고, 칩으로 바꿀 수 있습니다. 이모지·한 줄 설명도 고칠 수 있고 ✏️ 로 나중에 고칩니다. 지우면 좋아하는 메뉴·추천 제외에서도 빠집니다(되돌리기 가능). 최대 300개.
- **🚫 추천 제외** — 메뉴 이름으로 추가(목록에 있는 메뉴·직접 추가 메뉴만), ↩️ 다시 추천하기, 💗 로 좋아하는 메뉴로 옮기기. 여기 있는 메뉴는 추천 카드에 나오지 않습니다.
- 한 메뉴는 좋아하는 메뉴·추천 제외 중 한 곳에만 있습니다. 다른 목록에 있던 메뉴를 추가하면 자동으로 옮겨지고, 삭제·옮기기는 모두 되돌리기 가능합니다.
- 모든 탭에서 이름·종류·키워드 검색, 종류 필터, 정렬(최근 추가·이름·종류)을 지원합니다.
- **📦 내보내기 · 가져오기** — 아래 카드에서 직접 추가 메뉴·좋아하는 메뉴·추천 제외 중 고른 목록을 🔗 공유 링크(모바일은 공유 시트, PC 는 클립보드), 📋 텍스트(JSON), 💾 파일(`.json`)로 내보냅니다. 받는 쪽은 링크를 열거나 📂 파일 열기·📥 붙여넣기로 가져오고, 미리보기에서 목록별 새로/이미 있음 개수를 보고 **합치기**(내 메뉴 유지, 새 메뉴만 더함) 또는 **바꾸기**(고른 목록 통째로 교체)를 고릅니다. 가져온 뒤 `되돌리기` 로 이전 상태로 돌릴 수 있습니다. 자세한 형식은 아래 「내보내기 · 가져오기」 참고.

저장은 브라우저 `localStorage`(`what-to-eat:favorites:v1`, `what-to-eat:excluded:v1`, `what-to-eat:custom-menus:v1`)라 기기·브라우저마다 따로이고(옮길 때는 내보내기·가져오기), 다른 탭에서 바꿔도 바로 반영됩니다.

하늘은 고정 배경이고 히어로 아래 식탁이 덮습니다. 낮/밤은 Open-Meteo `is_day`, 날씨를 직접 고르면 하늘도 함께 바뀝니다. `prefers-reduced-motion` 이면 김·구름 같은 애니메이션을 멈춥니다.

## 추천 점수 규칙 (`recommend.js` → `recommend()`)

| 요소 | 점수 |
|---|---|
| 지역 특산 (역지오코딩 주소에 `부산`, `춘천`, `제주` 등 포함) | +6 |
| 계절 일치 / 사계절 메뉴 / 불일치 | +3 / +1 / −1 |
| 날씨 태그 일치 (상위 2개 합산) | 비·눈 +5, 더위·추위 +4, 그 외 +2 |
| 체감 10° 이하 + 뜨거운 국물 | +3 |
| 체감 27° 이상 + 뜨거운 국물 (이열치열 메뉴 제외) | −3 |
| 체감 27° 이상 + 차가운 음식 / 15° 이하 / 8° 이하 | +3 / −3 / −6 |
| 끼니 일치 / 불일치 | +2 / −2 |
| 반경 안에 이름이 일치하는 식당 있음 / 분류만 일치 | +2.5 / +0.5 |
| 📍 근처 식당 메뉴만일 때, 가장 가까운 메뉴 일치 식당 거리 | 0 ~ +3 (가까울수록, 반경 끝이면 0) |
| ✏️ 직접 추가한 메뉴 (`custom: true`, 근거 꼬리표 `내 메뉴`) | +1 |
| 무작위 (🎲 다시 추천 때만 바뀜) | 0 ~ 2 |

점수를 매기기 전에 제외 분류, 🚫 추천 제외 메뉴(`excludeNames`), 👶 아이와 함께일 때 `kid: false` 메뉴(`kidOnly`)는 후보에서 빼고, 🥗 가벼운 식사일 때는 `light: true` 메뉴(`lightOnly`)만, 🍶 반주·안주일 때는 `drink: true` 메뉴(`drinkOnly`)만 남깁니다. 📍 근처 식당 메뉴만(`nearOnly`)일 때는 반경 안에 그 메뉴를 파는 식당(메뉴 일치)이 확인된 메뉴만 남깁니다.

### 🥐 빵

`빵` 분류(46종)는 식사빵·샌드위치(소금빵·잠봉뵈르·깜빠뉴·BLT 샌드위치 등), 동네 빵집 빵(단팥빵·소보로빵·카레빵 등), 지역 명물(대전 튀김소보로·경주 찰보리빵·천안 호두과자·공주 밤빵), 페이스트리·구움과자(뺑오쇼콜라·휘낭시에·에그타르트 등)로 나뉩니다. 대부분 점심 메뉴이고, 설정의 음식 종류 칩에서 `빵` 을 끄면 추천에서 빠집니다.

- 카카오 분류 매칭은 `음식점 > 간식`(제과·베이커리·도넛)을 비슷한 종류로 봅니다. `베이커리`·`빵` 같은 넓은 말은 키워드에 넣지 않습니다.
- OSM 대체 검색은 `shop=bakery`·`pastry` 빵집도 함께 가져옵니다.
- 기존 분류에 있던 빵 메뉴(베이글·와플·붕어빵·계란빵 등)는 원래 분류에 그대로 둡니다.

### 📍 근처 식당 메뉴만

여행지처럼 낯선 곳에서 "지금 근처에서 실제로 먹을 수 있는 메뉴"만 추천받는 옵션입니다.

- 후보는 `nearbyCount()` 의 `exact > 0` 인 메뉴뿐입니다 — 음식점 풀(가까운 45곳)의 이름·카카오 세부 분류 일치, 또는 카카오 키워드 검색 결과가 있는 메뉴.
- 필터 전 순위(`state.pool`)에서 아직 확인 안 한 메뉴를 분류를 섞어 12개씩 키워드 검색합니다. 상위 12개는 항상 확인하고, 화면에 6개가 안 차면 더 내려가며 위치·반경당 최대 72개까지 찾습니다.
- 근거 줄은 `걸어서 2분(120m) 거리 · 근처 3곳` 처럼 가장 가까운 집까지의 거리를 보여줍니다.
- 확인 중에는 히어로에 "주변 식당에서 파는 메뉴를 살펴보고 있어요…", 식당 정보를 못 불러오면 끄라는 안내가 나옵니다.

계절은 월 기준(3–5 봄, 6–8 여름, 9–11 가을, 12–2 겨울, 남반구는 반전), 끼니는 15시 이전 점심입니다.

### 추천 근거 표시

`recommend()` 는 근거를 `{ kind, icon, text, pts }` 로 남기고(기여 점수 큰 순), 카드에는 두 가지로 보여줍니다.

- **대표 근거 배지** (`basis`) — `🌧️ 날씨 추천` · `🍁 계절 추천` · `📍 지역 추천`. 지역 특산이면 지역이 우선, 아니면 날씨·계절 중 기여 점수가 큰 쪽(체감온도 가산점은 날씨에 포함). 셋 다 없으면 `🍽️ 끼니 추천`, 그것도 없으면 `🎲 오늘의 랜덤`.
- **근거 줄마다 종류 꼬리표** — 날씨(파랑)·계절(주황)·지역(보라)·근처(초록)·끼니(회색). 큰 카드는 3줄, 작은 카드는 2줄.

화면에 보이는 6개는 `pickTop()` 으로 고릅니다. 1위는 항상 점수 1위이고, 같은 분류는 최대 2개까지만 넣어 떡볶이 여러 종처럼 비슷한 메뉴가 한꺼번에 나오지 않게 합니다. 제외 설정으로 분류가 모자라면 남은 점수 순서대로 채웁니다. 카카오 키워드 점수용 상위 12개 후보도 같은 방식(분류당 최대 4개)으로 고릅니다.

추천 후보는 `menus.js` 646종에 직접 추가 메뉴를 합친 `allMenus()` 입니다. 직접 추가 메뉴는 히어로에 `✏️ 내가 추가한 메뉴` 칩이 붙고, 이름이 카카오 검색어(`kw[0]`)라 근처 식당·지도·레시피 검색도 기존 메뉴와 똑같이 동작합니다.

## 내보내기 · 가져오기 (`transfer.js`)

```json
{ "app": "what-to-eat", "version": 1, "exportedAt": "2026-11-07T13:00:00.000Z",
  "custom": [{ "name": "닭칼국수", "emoji": "🍜", "cat": "한식", "temp": "hot", "seasons": ["autumn"],
               "weather": ["rain", "chilly"], "meal": "dinner", "kw": ["닭칼국수"], "desc": "회사 앞 단골집",
               "kid": true, "light": false, "drink": false, "ref": "칼국수", "addedAt": 1794056937054 }],
  "favorites": ["닭칼국수", "짬뽕"],
  "excluded": ["마라탕"] }
```

- 고른 목록만 들어 있습니다(`custom`·`favorites`·`excluded`).
- 공유 링크는 `favorites.html#import=<코드>` 이고, 코드 첫 글자 `z` 는 deflate-raw 압축(`CompressionStream`) + base64url, `j` 는 압축 없는 base64url 입니다. 데이터가 주소의 `#` 뒤에 있어서 서버로 전송되지 않습니다.
- 가져올 때 검사: `app`·`version` 확인, 이름 30자·설명 40자 등 길이 제한, 분류·온도·계절·날씨·끼니는 허용된 값만, 꺾쇠·제어문자 제거, 기존 메뉴와 이름이 겹치는 직접 추가 메뉴는 건너뜀, 직접 추가 300개·이름 목록 1000개까지.
- 같은 메뉴가 좋아하는 메뉴와 추천 제외 양쪽에 오면 추천 제외 쪽만 남깁니다. 정보 없이 이름만 받은 좋아하는 메뉴는 비슷한 메뉴 정보로 직접 추가 메뉴를 만들어 줍니다.

## 캐시 만료 · 새로 고침 (10분 단위)

날씨·주변 식당 풀·메뉴별 카카오 키워드 검색 결과는 **시계 기준 10분 칸**(`…:00`, `:10`, `:20` …)마다 만료됩니다(`app.js` 의 `CACHE_TTL`·`refreshData()`).

- 칸이 바뀌면 화면을 비우지 않고 뒤에서 날씨·식당을 새로 불러온 뒤 한 번에 바꿔 끼웁니다. 보고 있는 메뉴의 식당 목록도 미리 받아 두어 "찾는 중" 으로 깜빡이지 않습니다.
- 히어로 메뉴는 그대로 두고 점수·근거·근처 식당 수만 갱신합니다. 단, 끼니를 직접 고르지 않았고 시각이 바뀌어 점심 → 저녁이 되면 새로 추천합니다.
- 탭이 숨겨져 있으면 미뤘다가 다시 보일 때, 오프라인에서 돌아올 때(`online`), 뒤로 가기 캐시에서 복원될 때 만료 여부를 확인합니다.
- 새로 불러오기에 실패하면 이전 데이터를 그대로 두고 다음 칸에 다시 시도합니다. 진행 중에 위치·반경이 바뀌면 그 결과는 버립니다.
- 날씨 알약에 마우스를 올리면 `23:10 기준 · 10분마다 새로 고침` 처럼 마지막으로 불러온 시각이 보입니다.

## 위치 검색 (카카오)

- 검색창 입력은 먼저 **주소 검색**(`addressSearch`, 예: `춘천`, `테헤란로 152`)을 하고, 결과가 없으면 **장소 키워드 검색**(`keywordSearch`, 예: `강남역`, `코엑스`)으로 첫 결과를 씁니다. 키워드 검색은 현재 위치 근처를 우선합니다.
- 역지오코딩은 행정동(`H`)으로 화면 라벨(`서울특별시 강남구 역삼1동`)을, 법정동(`B`)으로 지도 링크용 동 이름(`역삼동`)을 만듭니다. 지역 특산 매칭에는 행정동·법정동·도로명 주소를 모두 씁니다.
- 국외 좌표는 카카오가 결과를 주지 않으므로 Nominatim 으로 대체합니다.

## 식당 검색 흐름 (카카오)

1. 위치·반경이 바뀌면 **카테고리 검색**(`FD6` 음식점)으로 가까운 순 최대 45곳을 풀로 받습니다.
2. 추천 상위 12개 메뉴(📍 근처 식당 메뉴만일 때는 6개가 찰 때까지 12개씩 더)는 **키워드 검색**(`kw[0]`, 음식점 카테고리 한정)을 한 페이지씩 돌려 전체 건수(`totalCount`)로 "근처에 파는 곳 N곳" 점수를 매기고 한 번 다시 정렬합니다.
3. 메뉴 카드를 고르면 그 메뉴의 키워드 검색을 3페이지(최대 45곳)까지 가져와 지도·목록에 표시합니다. 결과는 위치·반경이 바뀌거나 10분 칸이 바뀔 때까지 메뉴별로 캐시합니다.
4. 사용자가 카드를 직접 고른 상태면 재정렬 후에도 그 메뉴를 유지하고, 아니면 1위 메뉴를 따라갑니다.

## 식당 매칭 (`matchRestaurant()`)

- **메뉴 일치(2)**: 카카오 키워드 검색 결과 / 식당 이름에 `kw` 포함 / 카카오 분류(`음식점 > 한식 > 해장국`)의 세부 분류에 `kw` 포함
- **비슷한 종류(1)**: 카카오 2단계 분류가 메뉴 분류와 같음(`KAKAO_GROUPS`), 또는 OSM `cuisine` 태그 일치
- 카카오 검색은 한 검색당 최대 45건까지만 주므로, 더 많은 결과는 카카오맵·네이버지도 링크로 확인합니다.

## 레시피 검색 (`recipes.js`)

- 검색어는 선택한 추천 메뉴 이름(`설렁탕·곰탕` → `설렁탕`)입니다. 검색창을 직접 고치면 자동 재추천이 일어나도 그대로 두고, 카드를 직접 고르거나 `↺ 메뉴로` 를 누르면 메뉴로 돌아갑니다.
- 검색 방식 칩(기본·간단하게·황금레시피·1인분·에어프라이어)은 검색어 뒤에 붙습니다.
- 만개의레시피·유튜브·네이버·구글 검색 결과를 새 탭으로 엽니다. 검색 버튼(엔터)은 만개의레시피를 엽니다. 레시피 사이트는 브라우저에서 바로 부를 수 있는 공개 API 가 없어(CORS·키 필요) 링크 방식입니다.
- 최근 검색어는 `localStorage`(`what-to-eat:recipe-recent:v1`)에 최대 8개 저장합니다.

## 메뉴 추가하기

`menus.js` 에 추가합니다. 이름(`name`)은 전체에서 겹치면 안 됩니다(메뉴별 캐시 키).

분류별 `rows()` 목록에 한 줄로 넣는 방법이 간단합니다. `cuisine` 은 분류 기본값을 씁니다.

```js
// [이름, 이모지, 온도, 계절, 날씨, 끼니, 키워드, 설명, 지역]
["닭한마리", "🐔", "hot", "겨울", "cold snow", "저녁", "닭한마리", "칼국수 사리까지", "종로"],
```

- 온도 `hot` / `cold` / `""`(보통), 계절 `"가을 겨울"`(비우면 사계절), 끼니 `"점심"` / `"저녁"` / `""`(둘 다)
- 키워드는 공백으로 구분하고 첫 값이 카카오 검색어입니다. `태국`·`분식`처럼 넓은 말은 그 종류 식당이 모두 "메뉴 일치"가 되므로 넣지 않습니다.
- 맵거나 날것·내장·술안주 중심이라 아이와 먹기 어려운 메뉴면 `menus.js` 아래쪽 `NOT_KID` 목록에 이름을 넣습니다. 객체로 넣을 때는 `kid: false` 를 직접 적어도 됩니다.
- 국수·죽·김밥·샐러드·샌드위치처럼 부담 없이 먹는 메뉴면 `menus.js` 아래쪽 `LIGHT` 목록에 이름을 넣습니다(현재 129종). 객체로 넣을 때는 `light: true` 를 직접 적어도 됩니다.
- 술 한잔 곁들이기 좋은 구이·전·튀김·회·탕·꼬치 같은 메뉴면 `menus.js` 아래쪽 `DRINK` 목록에 이름을 넣습니다(현재 228종). 객체로 넣을 때는 `drink: true` 를 직접 적어도 됩니다.

세부 값이 필요하면 `MENUS` 배열에 객체로 넣어도 됩니다.

```js
{ name: "닭한마리", emoji: "🐔", cat: "한식", temp: "hot",
  seasons: ["winter"], weather: ["cold", "snow"], regions: ["종로"],
  meal: "dinner", kw: ["닭한마리"], cuisine: ["korean"], desc: "칼국수 사리까지" }
```
