# 오늘 뭐 먹지? 🍚

현재 위치의 **날씨·계절·지역 특산**과 **점심/저녁**을 반영해 메뉴를 추천하고, 그 메뉴를 파는 **주변 식당을 카카오맵과 목록**으로 보여주는 웹 앱입니다.
지도·식당 검색·위치 검색·주소 변환은 모두 **카카오맵 JavaScript SDK**를 쓰고, 카카오 키가 없거나 SDK 를 못 불러오면 OpenStreetMap(Leaflet·Overpass)으로 자동 대체됩니다.

## 카카오 키 설정

1. [Kakao Developers](https://developers.kakao.com) → 내 애플리케이션 → 앱 만들기
2. **앱 설정 → 플랫폼 → Web** 에 사이트 도메인 등록: `http://localhost:8000` (배포 주소도 추가)
3. **제품 설정 → 카카오맵** 사용 설정 ON
4. **앱 키 → JavaScript 키**를 `config.js` 의 `window.KAKAO_JS_KEY` 에 붙여넣기 (REST API 키 아님)

JavaScript 키는 등록한 도메인에서만 동작하므로 정적 호스팅에 그대로 올려도 됩니다.
키가 비어 있거나 SDK 로드가 실패하면 콘솔에 경고를 남기고 지도는 Leaflet + OSM 타일(필요할 때만 불러옴), 식당은 Overpass(OSM)로 대체합니다.

## 실행

위치 권한(Geolocation)은 `https` 또는 `localhost` 에서만 동작하므로 파일을 더블클릭하지 말고 로컬 서버로 여세요.

```bash
cd what-to-eat
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

배포는 GitHub Pages·Netlify 등 정적 호스팅에 폴더째 올리면 됩니다.

## 화면 구성

1. **히어로** — 화면 전체에 오늘 날씨의 하늘이 깔리고(맑음·구름 조금·흐림·안개·비·뇌우·눈·무더위·한파 × 낮/밤), 위치·날씨·계절 칩과 인사말(`비 내리는 토요일 저녁,`) 아래에 추천 1위 큰 카드 + 나머지 5개 카드가 바로 보입니다. 모바일에서는 나머지 카드를 가로로 넘겨 봅니다.
2. **주변 식당** — 카드를 누르면 지도·목록으로 스크롤됩니다.
3. **검색 · 추천 설정** — 위치 검색, 점심/저녁, 날씨 직접 선택, 반경, 음식 종류 제외. 위치를 바꾸면 맨 위로 돌아가 새 추천을 보여줍니다.

스크롤하면 하늘이 흐려지며 날씨별 바탕색(`--bg`)으로 자연스럽게 녹아듭니다. 낮/밤은 Open-Meteo `is_day`, 날씨를 직접 고르면 하늘도 함께 바뀝니다. `prefers-reduced-motion` 이면 애니메이션을 줄입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (날씨 히어로 + 추천 → 지도·식당 → 검색·설정 순) |
| `style.css` | 스타일 (모바일 대응) |
| `recommend.js` | 메뉴 데이터 50여 종 + 추천 점수 로직 (DOM 의존 없음, Node 에서 `require` 가능) |
| `config.js` | 카카오 JavaScript 키 |
| `kakao.js` | 카카오 래퍼 (SDK 로드, 카테고리·키워드 검색, 위치 검색 `geocode`, 역지오코딩 `reverseGeocode`) |
| `map.js` | 지도 래퍼 `MapView`: 카카오맵(내 위치 점·반경 원·식당 점·말풍선), 카카오 불가 시 Leaflet 으로 대체. 준비 전 호출은 기억했다가 반영 |
| `sky.js` | 날씨 하늘 배경: 날씨·낮밤별 그라데이션, 해·달·구름·안개(CSS), 비·눈·별(캔버스), 스크롤하면 바탕색으로 전환 (`Sky.set({ kind, night })`) |
| `app.js` | 위치·날씨·식당 검색 흐름, 렌더링과 이벤트 (지도는 `MapView` 로만 다룸) |

## 사용하는 외부 서비스

| 용도 | 서비스 |
|---|---|
| 현재 날씨 (기온·체감·습도·풍속·날씨코드·낮밤) | Open-Meteo |
| 위치 검색 (주소·역·건물 → 좌표) | **카카오** `Geocoder.addressSearch` → 없으면 `Places.keywordSearch` → 없으면 Nominatim |
| 좌표 → 동 이름 | **카카오** `coord2RegionCode`·`coord2Address` → 국외·실패 시 Nominatim |
| 주변 식당 검색 | **카카오 로컬** (Maps JS SDK `services`, JavaScript 키) → 없으면 OSM Overpass API |
| 지도 | **카카오맵** (`kakao.maps.Map`) → 없으면 Leaflet + OSM 타일 |
| 보조 검색 링크 | 카카오맵·네이버지도 검색 URL (`동 이름 + 메뉴`) |

## 추천 점수 규칙 (`recommend.js` → `recommend()`)

| 요소 | 점수 |
|---|---|
| 지역 특산 (역지오코딩 주소에 `부산`, `춘천`, `제주` 등 포함) | +6 |
| 계절 일치 / 사계절 메뉴 / 불일치 | +3 / +1 / −1 |
| 날씨 태그 일치 (상위 2개 합산) | 비·눈 +5, 더위·추위 +4, 그 외 +2 |
| 체감 10° 이하 + 뜨거운 국물 | +3 |
| 체감 27° 이상 + 뜨거운 국물 (이열치열 메뉴 제외) | −3 |
| 체감 27° 이상 + 차가운 음식 / 15° 이하 / 8° 이하 | +3 / −3 / −6 |
| 끼니 일치 / 불일치 | +2 / −2 |
| 반경 안에 이름이 일치하는 식당 있음 / 분류만 일치 | +2.5 / +0.5 |
| 무작위 (🎲 다시 추천 때만 바뀜) | 0 ~ 2 |

계절은 월 기준(3–5 봄, 6–8 여름, 9–11 가을, 12–2 겨울, 남반구는 반전), 끼니는 15시 이전 점심입니다.

## 위치 검색 (카카오)

- 검색창 입력은 먼저 **주소 검색**(`addressSearch`, 예: `춘천`, `테헤란로 152`)을 하고, 결과가 없으면 **장소 키워드 검색**(`keywordSearch`, 예: `강남역`, `코엑스`)으로 첫 결과를 씁니다. 키워드 검색은 현재 위치 근처를 우선합니다.
- 역지오코딩은 행정동(`H`)으로 화면 라벨(`서울특별시 강남구 역삼1동`)을, 법정동(`B`)으로 지도 링크용 동 이름(`역삼동`)을 만듭니다. 지역 특산 매칭에는 행정동·법정동·도로명 주소를 모두 씁니다.
- 국외 좌표는 카카오가 결과를 주지 않으므로 Nominatim 으로 대체합니다.

## 식당 검색 흐름 (카카오)

1. 위치·반경이 바뀌면 **카테고리 검색**(`FD6` 음식점)으로 가까운 순 최대 45곳을 풀로 받습니다.
2. 추천 상위 12개 메뉴는 **키워드 검색**(`kw[0]`, 음식점 카테고리 한정)을 한 페이지씩 돌려 전체 건수(`totalCount`)로 "근처에 파는 곳 N곳" 점수를 매기고 한 번 다시 정렬합니다.
3. 메뉴 카드를 고르면 그 메뉴의 키워드 검색을 3페이지(최대 45곳)까지 가져와 지도·목록에 표시합니다. 결과는 위치·반경이 바뀔 때까지 메뉴별로 캐시합니다.
4. 사용자가 카드를 직접 고른 상태면 재정렬 후에도 그 메뉴를 유지하고, 아니면 1위 메뉴를 따라갑니다.

## 식당 매칭 (`matchRestaurant()`)

- **메뉴 일치(2)**: 카카오 키워드 검색 결과 / 식당 이름에 `kw` 포함 / 카카오 분류(`음식점 > 한식 > 해장국`)의 세부 분류에 `kw` 포함
- **비슷한 종류(1)**: 카카오 2단계 분류가 메뉴 분류와 같음(`KAKAO_GROUPS`), 또는 OSM `cuisine` 태그 일치
- 카카오 검색은 한 검색당 최대 45건까지만 주므로, 더 많은 결과는 카카오맵·네이버지도 링크로 확인합니다.

## 메뉴 추가하기

`recommend.js` 의 `MENUS` 배열에 항목을 추가합니다.

```js
{ name: "닭한마리", emoji: "🐔", cat: "한식", temp: "hot",
  seasons: ["winter"], weather: ["cold", "snow"], regions: ["종로"],
  meal: "dinner", kw: ["닭한마리"], cuisine: ["korean"], desc: "칼국수 사리까지" }
```
